# webaudits.org Translation Glossary

This glossary defines approved translations for key terms used across webaudits.org. Before translating into a new language, fill in the target language column and get it approved. Use these translations consistently across all files — do not deviate without updating the glossary first.

## Instructions for completing the glossary

1. Add a column for the target language
2. For each term, propose a translation
3. Review and approve the translations before starting file translation
4. Include the completed glossary in every translation session prompt

## Notes for New Languages

- The four ECOS category names (Efficient, Clean, Open, Safe) are never translated in any language.
- "Score" is kept in English in all languages as part of "ECOS Score", "Total Score", "Sub-score" etc.
- Technical acronyms (HTTP, SSL, CSP, API, SEO, CDN, etc.) are never translated.
- Brand and product names (Lighthouse, PageSpeed, AbuseIPDB, DynamoDB, etc.) are never translated.
- Percentile labels (p10, p25, p50, p75, p90) are never translated.
- Placeholders ({{domain}}, {{date}}, {{score}}, etc.) are never translated or modified.
- "Aviso legal" in Spanish is the standard equivalent of the German Impressum (legally required disclosure page). Adapt as needed per country.
- Spanish uses gendered forms; defaults in this glossary follow the most natural/neutral form.
